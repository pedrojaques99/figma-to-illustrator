# Visant Exporter — by Pedro Jaques

**Visant Exporter** (Visant Labs Plugin) is a high-performance, essentialist Figma plugin designed for designers who need to bridge the gap between Figma and Adobe Illustrator with precision. It specializes in batch-exporting frame assets with background isolation, high-resolution rasterization, and organized ZIP outputs.

---

## ⚡ Features

- **Background Isolation**: Automatically hides vector elements and texts to export clean background layers.
- **High-Resolution Exports**: Support for 2X and 5X scale PNGs.
- **Clean SVG Output**: Optional SVG version included for vector-perfect layouts.
- **Smart Batching**: Exports multiple selected frames into organized ZIP folders.
- **Rich Terminal Feedback**: Real-time logging of the encoding process directly in the plugin UI.
- **Essentialist UI**: Compact, Figma-native design that stays out of your way.

## 🚀 How to Run Locally

### Prerequisites
- [Node.js](https://nodejs.org/) installed on your machine.
- [Figma Desktop App](https://www.figma.com/downloads/).

### Setup
1. **Clone the repository:**
   ```bash
   git clone https://github.com/pedrojaques99/figma-to-illustrator.git
   cd figma-to-illustrator
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Add to Figma:**
   - Open Figma Desktop.
   - Go to `Plugins` -> `Development` -> `Import plugin from manifest...`.
   - Select the `manifest.json` file in this project's root.
